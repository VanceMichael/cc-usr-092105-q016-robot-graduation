# 机器人毕业能力交接

为每台机器人保存从课堂到职场的能力档案：硬件配置、软件版本、课程任务、实战记录、故障处置、能力证据、认证范围与毕业码。接收方扫毕业码即可确认它当前会做什么、在哪些场景测试过、最近换件后哪些能力尚未复验；一张只写“毕业”的证书没有实际价值。

## 资料范围

| 文件 | 作用 |
| --- | --- |
| `contracts/domain.schema.json` | 约束交换资料的结构（字段、枚举、签署人数等） |
| `fixtures/domain.json` | 不含真实个人信息的业务样例：导览机“小舟”与巡检机“铁哨” |
| `docs/domain.md` | 领域对象、业务规则与样例线索 |
| `src/domain.py` | 读取、规则校验、扫码解析与交接视图（仅标准库） |
| `tests/test_domain.py` | 结构、结论、扫码、交接与规则变异测试 |

## 能力概览

- `load_domain` / `validate_domain`：校验引用完整性、赋码约束、多方签署、离线补传时序、变化→复验一致性、事件链只追加、撤销与交接前提。
- `resolve_code`：模拟扫码，返回码状态（有效 / 含待复验 / 失效）、各项能力当前结论、测试场景、待复验清单；失效码会指向沿同一身份新发的码。
- `handover_view`：接收方只看到岗位所需能力的当前结论。
- `full_history`：学校沿原机器人身份保留完整历史。

当前资料确认了以下事实：

- 四台机器人经过两个多月培训和实战后获得毕业身份
- 机器人类型包括导览、巡检和钢琴表演
- 毕业后将进入场馆、学校、工厂和海外场景
- 导览机更换激光雷达后避障能力已复验、夜间巡场待复验
- 巡检机经历模型升级、退回返修、证书撤销与重新赋码后交接海外

## 校验方式

在仓库根目录运行：

```bash
python3 -m unittest discover -s tests -v
```

测试会读取样例，核对对象清单与全部业务规则，并对合规样例做单点变异验证每条规则都能拦下。
